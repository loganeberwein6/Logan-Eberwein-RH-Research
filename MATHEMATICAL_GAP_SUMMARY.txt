3. WHAT IS THE FIRST GENUINE UNRESOLVED GAP?
======================================================================

The first genuine unresolved mathematical gap is:

    NO PROVED ASYMPTOTIC BOUND ON SR_weil_form_real X beta gamma.

The project has proved (at SR_Bridge.lean) a Cauchy-Schwarz inequality
and an Abel summation identity for finite sums. It has computed
SR_weil_form_real 6 (1/2) 0 = 14 and SR_weil_form_real 30 (1/2) gamma
for specific gamma values. But no proved theorem gives the behavior of
the Weil form as X -> infinity, not even the sign of the leading term.

Without this, every downstream claim about the SR form as X -> infinity
is conjectural. The growth law conjecture (SR_growth_law_conjecture)
asserts a two-sided bound X^(3*beta-epsilon) << Q_X << X^(3*beta), but:
  (a) this is merely a declared Prop, not a proved theorem;
  (b) Research/KilledApproaches.md records that Q_X/X^(3*beta) at
      fixed beta=0.8, gamma=21.022 is DECREASING as X grows, which
      is inconsistent with the lower bound in the conjecture.

Closing this gap requires: an Abel summation lemma for SR_A_weighted X
with a provable explicit error term, plus a proved cancellation estimate
for the off-diagonal terms in the convolution sum.

4. NEXT 5 HIGHEST-PRIORITY MATHEMATICAL GAPS
======================================================================

GAP-A: Sign convention derivation
  File: SR_Signature.lean, SR_Flow.lean
  The assignment Interior -> -1, Exit -> +1 is assumed as external
  motivation (Hodge index). There is no formal Lean proof deriving
  it from the Selberg explicit formula or a Weil positivity theorem.
  SR15_REDUCTION_AUDIT_OPEN and SR15_SIGN_ARITHMETIC_OPEN are
  both `True`, recording this as open.
  PRIORITY: High. All spectral sign computations rest on this assumption.

GAP-B: Uniform asymptotic estimate for SR_A_weighted
  File: SR_Bridge.lean, SR_Stage29.lean
  The Abel summation framework is in place but the error estimate
  is not proved. Need: |SR_A_weighted X beta gamma| bounded uniformly
  in some useful range of X.
  PRIORITY: High. Prerequisite for any RH-adjacent claim.

GAP-C: Connection between SR_rees_matrix and SR_signed_threshold_matrix
  File: SR_Stage38.lean
  The abstract negative-definiteness result (SR_threshold_matrix_quadratic_form)
  applies to any strictly monotone index sequence. For SR_rees_matrix X
  the relevant sequence is the floor quotient sequence (X-1)/(m+2), which
  is NOT strictly monotone (equal values produce zero blocks). The connection
  from the abstract result to SR_rees_matrix is stated but not fully proved
  as a general theorem for all X >= 6.
  PRIORITY: Medium-high. Needed to apply spectral results to the actual matrix.

GAP-D: General signature sequence for all X >= 6
  File: SR_Flow.lean, SR_SignatureBound.lean
  Signatures are computed by native_decide at X in {5/2, 6, 30} and
  by a signature bound table for X in [6,200]. No proved formula gives
  the signature pattern for all X.
  PRIORITY: Medium. Needed for any limiting argument.

GAP-E: dBN limit theorem
  File: SR_Flow.lean
  SRdBN_conjectural_bridge_limit_open is literally `True`. A genuine
  theorem is needed of the form: as X -> infinity, the normalized
  signature ratio of SR_rees_matrix X converges to a value that, via
  some proved bridge, restricts the location of zeta zeros.
  PRIORITY: Medium (but blocked by all gaps above).

5. WHICH GAPS ARE MERELY LEAN/API REPAIRS VS. MATHEMATICS?
======================================================================

LEAN/API REPAIRS (not deep mathematics -- fixable with Lean engineering):

  L1: List.sum_congr is unavailable in current Mathlib; workaround
      used with Finset.sum. This is a Lean API compatibility issue.
      (Recorded in Research/FailureInvariants.md)

  L2: Coercion obstacles (Nat -> Real, Fin n -> Nat) in Abel summation.
      These caused proof failures in early Stage 29 attempts and required
      restatement of intermediate lemmas with explicit coercions.

  L3: Index arithmetic for SR_Stage38 row parameterization. The index
      convention (i+2)*(j+2) < X requires careful Fin/Nat casting.
      Some of the more involved `native_decide` calls could be replaced
      by `decide` (kernel-checked) with better coercion handling.

  L4: SR_Stage36 Dirichlet/L-series API usage: `sr37_lseries_of_dirichlet_convolution_eq_product`
      uses a Mathlib theorem but required careful handling of
      multiplicativity conditions.

6. CLAIMS THAT MUST NOT BE MADE (UNSUPPORTED)
======================================================================

The following claims would be false, misleading, or not supported by
anything in this repository:

  CLAIM 1 (FALSE): "W_SR_RH_bridge proves that W_SR_converges implies RH."
  REALITY: W_SR_RH_bridge := W_SR_converges -> True. This is a tautology
  that is true regardless of whether W_SR_converges holds and regardless
  of whether RH is true. It has no mathematical content.

  CLAIM 2 (FALSE): "The project has established a de Bruijn-Newman bridge."
  REALITY: The dBN bridge scaffold (SRdBNBridgeScaffold) has all fields
  proved as `trivial`. There is no analytic content.

  CLAIM 3 (FALSE): "The SR growth law has been verified numerically."
  REALITY: Research/Stage29_SolutionMap.md records that Q_X/X^(3*beta)
  decreases as X grows at fixed beta=0.8, gamma=21.022, which contradicts
  the lower bound of SR_growth_law_conjecture. The conjecture is not proved
  and appears empirically questionable.

  CLAIM 4 (FALSE): "The Cauchy-Schwarz bound in SR_Bridge.lean bounds
  the Weil form from above."
  REALITY: The proved bound SR_Sint_log X^2 <= SR_S3_log * SR_S2_log
  is a correct inequality for finite weighted sums. It does NOT directly
  bound SR_weil_form_real X beta gamma unless additional steps are proved.

  CLAIM 5 (FALSE): "The sign convention Interior -> -1 is derived from
  the Selberg explicit formula."
  REALITY: SR15_SIGN_ARITHMETIC_OPEN and SR15_REDUCTION_AUDIT_OPEN are
  both `True`, explicitly marking this derivation as open. The sign
  assignment is externally motivated.

  CLAIM 6 (FALSE): "The Rees rank theorem connects to zeta zeros."
  REALITY: SR_rees_rank_eq_quotient_count correctly proves that
  rank(SR_rees_matrix X) = #{distinct floor quotients (X-1)/(m+2)}.
  This is a combinatorial fact about an integer matrix. It does not
  connect to zeros of the Riemann zeta function.

  CLAIM 7 (FALSE): "The project builds formally on Mathlib's riemannZeta."
  REALITY: Mathlib's riemannZeta is imported (SR_Stage36, SR_Stage37_Clean)
  via LSeries/MellinTransform, but no proved theorem in this repository
  uses riemannZeta to conclude anything about SR constructions. The import
  is structural (for formal definitions), not substantive.

  CLAIM 8 (MISLEADING): "The project has no sorry or admit."
  NUANCE: True in the technical sense (no sorry/admit in proofs). But the
  project uses several `True` placeholder theorems and a definitional
  tautology (W_SR_RH_bridge) that achieve the same effect of marking open
  problems as compiled while carrying no mathematical content.
