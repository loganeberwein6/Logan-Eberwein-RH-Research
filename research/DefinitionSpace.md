# Definition space for the SR proportion

| Definition family | Cauchy-compatible? | Arithmetic fidelity |
|---|---|---|
| Literal `log(m) log(n)` in S1, S2, S3 | Yes in principle | Moderate; includes all integers uniformly |
| von Mangoldt in S1, S2, S3 | Yes in principle | Highest for explicit-formula work |
| Literal logs in S1, von Mangoldt in S2/S3 | No | Inconsistent |
| Unsigned sum `S_int+S_ext` with signed S1 | No decomposition equality | Sign-inconsistent |
| Signed sum `S_ext-S_int` | Correct Rees sign | Requires matching weight family |

The minimal sound set for a finite Cauchy theorem is one common nonnegative
weight family, one signed Rees sum, and matching reciprocal-product factors.
The optimal analytic family is von Mangoldt, but it requires more arithmetic
infrastructure than the literal-log branch.
